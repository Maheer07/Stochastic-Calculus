### Recall
The BSM equation ∂f/∂t + rS f_S + ½σ²S² f_SS = rf contains **no μ**. So any assumption about μ gives the same price, and the most convenient one is μ = r. That's risk-neutral valuation, which we did on trees on Day 5. Today it gives the famous formula.

### Today's concept
*Hull: "The Black–Scholes–Merton Model" — "Risk-Neutral Valuation" (incl. "Application to Forward Contracts on a Stock") and "Black–Scholes–Merton Pricing Formulas".*

**Risk-neutral valuation (continuous time).**
1. Assume the stock's expected return is **r**: dS = rS dt + σS dz.
2. Compute the expected payoff at T in that world, **Ê[payoff]**.
3. Discount at r: **f = e^{−rT} Ê[payoff]**.

*Quick check — a forward:* payoff S_T − K, and Ê[S_T] = S₀e^{rT} (Day 2's E[S_T] = S₀e^{μT} with μ = r). So f = e^{−rT}(S₀e^{rT} − K) = **S₀ − Ke^{−rT}** ✓, the same as yesterday's PDE check.

**The Black–Scholes–Merton formulas.** Apply the recipe to max(S_T − K, 0) with S_T lognormal (μ = r) and you get:

  **c = S₀ N(d₁) − K e^{−rT} N(d₂)**
  **p = K e^{−rT} N(−d₂) − S₀ N(−d₁)**

  **d₁ = [ ln(S₀/K) + (r + σ²/2)T ] / (σ√T)**,  **d₂ = d₁ − σ√T**

N(x) is the standard normal CDF: the probability that a φ(0, 1) variable is below x. In Python, N(x) = 0.5·(1 + erf(x/√2)). The derivation is an integral of the lognormal density, which Hull does in the appendix. Tomorrow covers what each piece *means*.

**Worked example** (S₀ = 100, K = 105, r = 4%, σ = 25%, T = 9 months):
- σ√T = 0.25 × √0.75 = 0.2165
- d₁ = [ln(100/105) + (0.04 + 0.03125)(0.75)] / 0.2165 = (−0.04879 + 0.05344)/0.2165 = **0.0215**
- d₂ = 0.0215 − 0.2165 = **−0.1950**
- N(d₁) = **0.5086**, N(d₂) = **0.4227**, Ke^{−rT} = 105e^{−0.03} = **101.90**
- **c = 100 × 0.5086 − 101.90 × 0.4227 = 7.79**
- **p = 9.68**. Check put–call parity: c − p = −1.90 = S₀ − Ke^{−rT} ✓

**Code** (formula vs risk-neutral Monte Carlo):
```python
import numpy as np
from math import log, sqrt, exp, erf
N = lambda x: 0.5*(1 + erf(x/sqrt(2)))                   # standard normal CDF
def bs_call(S, K, r, sigma, T):
    d1 = (log(S/K) + (r + sigma**2/2)*T) / (sigma*sqrt(T)); d2 = d1 - sigma*sqrt(T)
    return S*N(d1) - K*exp(-r*T)*N(d2)
S, K, r, sigma, T = 100, 105, 0.04, 0.25, 0.75
rng = np.random.default_rng(42)
ST = S*np.exp((r - sigma**2/2)*T + sigma*np.sqrt(T)*rng.standard_normal(1_000_000))  # μ = r
print(bs_call(S, K, r, sigma, T), np.exp(-r*T)*np.maximum(ST - K, 0).mean())       # 7.787 vs ≈ 7.791
```

> **Common pitfall.** Using the stock's real expected return μ in d₁ and d₂. The formula uses **r**. Two investors who disagree about μ still agree on the option price.

## Solutions

**Q1: A (S₀e^{rT}).** In the risk-neutral world the stock grows at r on average. B is the real-world mean. C has no growth. D is the risk-neutral *median*, not the mean.

**Q2.** (a) d₁ = (0 + (0.05 + 0.045) × 1)/0.3 = **0.3167**; d₂ = 0.3167 − 0.3 = **0.0167**. (b) c = 50 × 0.6243 − 50e^{−0.05} × 0.5066 = 31.21 − 47.56 × 0.5066 = **7.12**. (c) p = c − S₀ + Ke^{−rT} = 7.12 − 50 + 47.56 = **4.68**.

**Q3.** Formula **7.787**; Monte Carlo (seed 42, 10⁶ paths) ≈ **7.791 ± 0.014**, within one standard error. The BSM residual of the formula ≈ **0** (about 10⁻⁵, finite-difference noise): the formula really does solve the BSM equation, with payoff max(S − K, 0) as its boundary condition.
