### Today's concept
*Hull: "The Black–Scholes–Merton Model" — "Understanding N(d₁) and N(d₂)" and "Properties of the Black–Scholes–Merton Formulas".*

**Read the call as "what you get minus what you pay".** At expiry, if S_T > K you receive the stock and pay K. Taking risk-neutral expectations and discounting:
  c = e^{−rT} Ê[S_T · 1{S_T > K}] − Ke^{−rT} · P̂(S_T > K)
(1{·} is 1 if the event happens and 0 otherwise.) Matching this with the formula:
- **N(d₂) = P̂(S_T > K)**: the **risk-neutral probability the call is exercised**. So Ke^{−rT}N(d₂) is the present value of the strike, weighted by how likely you are to pay it.
- **S₀N(d₁) = e^{−rT} Ê[S_T · 1{S_T > K}]**: the present value of the stock you receive, counting only the paths where you exercise.

**N(d₁) is also the hedge ratio.** It equals **∂c/∂S**, the call's delta: the number of shares in Friday's riskless portfolio (Day 19). Note that N(d₁) > N(d₂). Delta is *not* the exercise probability.

*Our example* (S₀ = 100, K = 105, r = 4%, σ = 25%, T = 0.75; c = 7.79):
- N(d₂) = **0.423**: a 42.3% risk-neutral chance of finishing above 105.
- N(d₁) = **0.509**: hedge each short call with 0.509 shares.
- Pieces: S₀N(d₁) = 50.86, Ke^{−rT}N(d₂) = 43.07, difference **7.79** ✓.
- **Real-world** exercise probability: put μ in place of r in d₂. With μ = 12%, that's **53.3%**, not 42.3%. Risk-neutral probabilities are for pricing, not forecasting (the Day 5 pitfall).

**Sanity checks (Hull's properties).**
- **S₀ very large**: d₁, d₂ → ∞, N → 1, so c → S₀ − Ke^{−rT}, a forward. At S₀ = 200: c = 98.111 vs 98.103.
- **S₀ very small**: N → 0, so c → 0.
- **σ → 0**: the stock grows like a bond, so c → max(S₀ − Ke^{−rT}, 0). At S₀ = 100 that's **0** (since 100 < 101.90); at S₀ = 110 it's **8.10**.

**Code** (check both meanings):
```python
import numpy as np
from math import log, sqrt, exp, erf
N = lambda x: 0.5*(1 + erf(x/sqrt(2)))
def bs_call(S, K=105, r=0.04, sigma=0.25, T=0.75):
    d1 = (log(S/K) + (r + sigma**2/2)*T) / (sigma*sqrt(T)); d2 = d1 - sigma*sqrt(T)
    return S*N(d1) - K*exp(-r*T)*N(d2), N(d1), N(d2)
c, Nd1, Nd2 = bs_call(100)
rng = np.random.default_rng(42)
ST = 100*np.exp((0.04 - 0.25**2/2)*0.75 + 0.25*np.sqrt(0.75)*rng.standard_normal(1_000_000))
print(Nd2, (ST > 105).mean())                             # 0.4227 vs ≈ 0.4226: exercise probability
print(Nd1, (bs_call(100.01)[0] - bs_call(99.99)[0])/0.02) # 0.5086 vs 0.5086: the call's delta
```

> **Common pitfall.** Saying "the call has a 51% chance of finishing in the money" because delta is 0.51. Delta is N(d₁). The risk-neutral exercise probability is N(d₂), which is smaller, and the real-world probability is different again.
