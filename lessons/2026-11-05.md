### Today's concept
*Hull: "Wiener Processes and Itô's Lemma" — the technical note / appendix on Itô's lemma ("why (Δz)² = Δt"). Read it after today's lesson.*

**The puzzle.** Let G = z², where z is a Wiener process starting at 0. In ordinary calculus a tiny change gives
  ΔG = 2z Δz + (Δz)²,
and the (Δz)² term is "second order": far smaller than the first term, so we drop it. If we dropped it here, G would change by 2z Δz alone. That averages zero (Δz is independent of the current z), so E[z(T)²] would stay 0. But Day 10 told us z(T) ~ φ(0, T), so **E[z(T)²] = T**. The dropped term carries *everything*.

**Why (Δz)² isn't negligible.** (Δz)² = ε²Δt. Using E[ε²] = 1 and E[ε⁴] = 3 (facts about the normal):
- E[(Δz)²] = **Δt**: the same size as a drift term, not smaller.
- Var[(Δz)²] = Δt² × Var(ε²) = **2Δt²**: tiny compared with Δt when Δt is small.

So (Δz)² is "Δt, plus a wobble that's much smaller than Δt".

**Add it up over [0, T].** With N = T/Δt steps:
- Σ(Δz)² has mean N × Δt = **T**,
- and variance N × 2Δt² = 2TΔt → **0** as Δt → 0.

In the limit the sum of squared moves is *not random*: it equals exactly T. (Experts call this the *quadratic variation* of z.) That's what licenses Hull's shorthand **(dz)² = dt**.

**The multiplication table for small quantities** (you'll use it in every Itô calculation):
| × | dt | dz |
|---|---|---|
| **dt** | 0 | 0 |
| **dz** | 0 | **dt** |

- dt × dt = (Δt)²: second order, so it vanishes.
- dt × dz ~ Δt^{3/2}: also vanishes.
- dz × dz = dt: survives.

**Back to the puzzle.** Keep (Δz)² = dt and you get **d(z²) = 2z dz + dt**. The 2z dz part averages zero; the dt part adds up to T. So E[z(T)²] = T ✓. This is Itô's lemma in miniature, and tomorrow's lesson does it in general. (A callback to Day 3: the coin game X_n² − n was the "fair" one. Same idea: z² − t has no drift.)

**Code** (Σ(Δz)² settles at 1 as steps shrink):
```python
import numpy as np
for n in (10, 100, 1000, 10000):                 # number of steps in 1 year
    rng = np.random.default_rng(42)
    dz = rng.standard_normal((2000, n)) * np.sqrt(1/n)
    qv = (dz**2).sum(axis=1)                     # Σ(Δz)² on each of 2,000 paths
    print(n, qv.mean().round(4), qv.std().round(4))   # mean ≈ 1, spread ≈ √(2/n) → 0
```
Output: the mean stays ≈ 1.00, and the spread falls **0.45 → 0.14 → 0.044 → 0.014**.

> **Common pitfall.** Dropping (Δz)² as "second order" because Δz is small. Δz is small, but it's of order √Δt, so its square is of order Δt: the same order as the drift terms you keep. Only products with *more* than one power of Δt vanish.
