### Recall

### Today's concept
*Hull: "Wiener Processes and Itô's Lemma" — "Correlated Processes", and the technical note/appendix on Itô's lemma for several variables.*

**Correlated processes.** Two variables:
  dx₁ = a₁ dt + b₁ dz₁,  dx₂ = a₂ dt + b₂ dz₂,
where dz₁ and dz₂ are Wiener processes with correlation ρ. In the multiplication table from Day 13 this adds one new rule:
  **dz₁ · dz₂ = ρ dt** (and still dz₁² = dz₂² = dt, with any dt product = 0).

**Simulating them (Hull's recipe).** Draw two independent standard normals u and v, then set
  **ε₁ = u,  ε₂ = ρu + √(1 − ρ²)·v**.
Then ε₂ is still φ(0, 1), and corr(ε₁, ε₂) = ρ. *Check:* Var(ε₂) = ρ² + (1 − ρ²) = 1 ✓; Cov(ε₁, ε₂) = ρ ✓.

**Itô's lemma for G(x₁, x₂, t).** Taylor-expand to second order and apply the table:
  dG = [ G₁a₁ + G₂a₂ + G_t + ½G₁₁b₁² + ½G₂₂b₂² + **G₁₂ b₁b₂ρ** ] dt + G₁b₁ dz₁ + G₂b₂ dz₂,
where G₁ = ∂G/∂x₁, G₁₂ = ∂²G/∂x₁∂x₂ and so on. Compared with the one-variable version, the only new piece is the **cross term G₁₂ b₁b₂ρ dt**, from dz₁·dz₂ = ρ dt.

**Worked example: a foreign stock in your own currency.** A US stock S₁ (μ₁ = 8%, σ₁ = 20%) and the $→£ exchange rate S₂ (μ₂ = 2%, σ₂ = 10%), with correlation ρ = −0.3. In pounds the stock is worth P = S₁S₂. Partials: P₁ = S₂, P₂ = S₁, P₁₁ = P₂₂ = 0, P₁₂ = 1. So:
  dP = (μ₁ + μ₂ + ρσ₁σ₂)P dt + σ₁P dz₁ + σ₂P dz₂.
- Drift: 0.08 + 0.02 − 0.3 × 0.2 × 0.1 = **9.4%**. The correlation term costs 0.6% a year.
- Volatility (the two dz terms combined, Day 9: variances add, plus the covariance): √(σ₁² + σ₂² + 2ρσ₁σ₂) = √0.038 = **19.5%**. That's below the stock's own 20%: the negative correlation partly cancels the FX risk.

**Code:**
```python
import numpy as np
rng = np.random.default_rng(42)
n, M = 252, 100_000; dt = 1/n; rho = -0.3
S1 = np.ones(M); S2 = np.ones(M)
for _ in range(n):
    u, v = rng.standard_normal(M), rng.standard_normal(M)
    e1, e2 = u, rho*u + np.sqrt(1 - rho**2)*v            # correlated shocks
    S1 *= 1 + 0.08*dt + 0.2*np.sqrt(dt)*e1
    S2 *= 1 + 0.02*dt + 0.1*np.sqrt(dt)*e2
P = S1 * S2
print(P.mean(), np.log(P).std())   # ≈ 1.0995 (theory e^0.094 = 1.0986), ≈ 0.195
```

> **Common pitfall.** Assuming E[S₁S₂] = E[S₁]·E[S₂]. That only holds when ρ = 0. Here E[S₁]E[S₂] ≈ e^{0.10} = 1.105, but E[P] ≈ 1.099: the cross term ρσ₁σ₂ is exactly the difference.

### Module B in six lines
1. **Markov**: only today's value matters; variances add, so uncertainty ∝ √time (Day 9).
2. **Wiener process**: Δz = ε√Δt, independent increments, z(T) ~ φ(0, T) (Day 10).
3. **Generalized Wiener / Itô process**: dx = a dt + b dz, with a and b possibly depending on x and t (Day 11).
4. **Stock model**: dS = μS dt + σS dz (Day 12).
5. **(dz)² = dt**: the multiplication table (Day 13), plus dz₁dz₂ = ρ dt (today).
6. **Itô's lemma**: dG = (G_S μS + G_t + ½G_SS σ²S²) dt + G_S σS dz, which gives d(ln S) = (μ − σ²/2) dt + σ dz, so S_T is lognormal (Days 14–15).
