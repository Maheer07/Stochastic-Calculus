### Recall
Backward induction: start from the payoffs at expiry and repeatedly apply f = e^{−rΔt}[p f_u + (1 − p) f_d]. Today: (1) options you may exercise *early*, and (2) choosing u and d from a real volatility σ instead of making them up.

### Today's concept
*Hull: "Binomial Trees" — "American Options", "Matching Volatility with u and d", and "Increasing the Number of Steps".*

**Matching volatility.** So far u = 1.1 and d = 0.9 were invented. Hull ties them to the stock's volatility σ:
  **u = e^{σ√Δt}, d = 1/u = e^{−σ√Δt}**.
That choice makes the tree's return variance over each step ≈ σ²Δt, the same as the real stock's. With our running σ = 0.2 and Δt = 0.25: u = e^{0.1} = **1.1052**, d = **0.9048**. That's almost exactly the 1.1/0.9 tree you've been using. With r = 4%, p = (e^{0.01} − 0.9048)/(1.1052 − 0.9048) = **0.5252**.

**American options.** A European option can only be exercised at expiry. An **American** option can be exercised at any time. On a tree that means one extra check at every node:
  **node value = max( continuation value, value if exercised now )**
where the continuation value is the usual e^{−rΔt}[p f_u + (1 − p) f_d].

**Worked example: 2-step American put**, S₀ = 100, K = 100, T = 6 months.
- Expiry prices 122.14, 100, 81.87 → put payoffs 0, 0, 18.13.
- At S = 110.52: continuation 0, exercise now 0 → **0**.
- At S = 90.48: continuation e^{−0.01}(0.5252 × 0 + 0.4748 × 18.13) = 8.52, but **exercise now = 100 − 90.48 = 9.52**. So exercise early → **9.52**.
- Today: continuation e^{−0.01}(0.4748 × 9.52) = **4.474** (exercising now pays 0).

The European put (no early exercise) is **4.006**, so the right to exercise early is worth **0.47** here. Why exercise a put early? At S = 90.48 you can bank 9.52 now and earn interest on it. Waiting risks the stock bouncing back.

**American calls (no dividends) are never exercised early.** Exercising gives S − K now, but holding the call is always worth at least S − Ke^{−r(T−t)}, which is more. So an American call is worth the same as a European call.

**Increasing the number of steps.** Two steps is crude. As n grows (with Δt = T/n), the European put price converges:
| steps n | 2 | 10 | 50 | 200 | 1000 | Black–Scholes |
|---|---|---|---|---|---|---|
| put | 4.006 | 4.508 | 4.619 | 4.640 | 4.646 | **4.647** |

That limit is Black–Scholes. In practice, trees use 30–500 steps.

**Code:**
```python
import numpy as np
def tree(S0, K, r, sigma, T, n, kind="put", american=False):
    dt = T / n
    u = np.exp(sigma*np.sqrt(dt)); d = 1/u            # Hull's volatility matching
    p = (np.exp(r*dt) - d) / (u - d)
    payoff = lambda S: np.maximum(S-K, 0) if kind == "call" else np.maximum(K-S, 0)
    S = S0 * u**np.arange(n, -1, -1) * d**np.arange(0, n+1)   # expiry prices, highest first
    f = payoff(S)
    for _ in range(n):
        S = S[:-1] / u                                   # stock prices one step earlier
        f = np.exp(-r*dt) * (p*f[:-1] + (1-p)*f[1:])     # continuation value
        if american: f = np.maximum(f, payoff(S))        # early-exercise check
    return f[0]
print(tree(100, 100, 0.04, 0.2, 0.5, 2, american=True))  # 4.4735
print(tree(100, 100, 0.04, 0.2, 0.5, 2))                 # 4.0057 (European)
```

> **Common pitfall.** Checking for early exercise only at today's node, or comparing exercise against the *European* value. The check must happen at **every** node, using the continuation value that already includes the early-exercise choices further down the tree.
