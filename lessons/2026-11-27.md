### Today's concept
*Hull: "Volatility Smiles" — "Why the Volatility Smile Is the Same for Calls and Puts", "Foreign Currency Options", "Equity Options" and "Volatility Surfaces".*

**The volatility smile** is a plot of implied vol (Day 23) against strike K, for one maturity. Traders still *quote* option prices in BSM implied vols, but they use a different σ for each strike.

**Same smile for calls and puts.** Put–call parity, c − p = S₀ − Ke^{−rT}, holds for market prices (it's a pure no-arbitrage argument, Day 22). It also holds for BSM prices at any σ. Subtract the two equations:
  **c_mkt − c_BSM = p_mkt − p_BSM**.
So if σ = 23% makes the BSM call match the market call, the same σ makes the BSM put match the market put. **One smile serves both.**

**What it tells you: the true distribution isn't lognormal.**
- **FX options: a smile** (higher implied vol for both low and high strikes). Both tails are fatter than lognormal, because FX vol isn't constant and rates jump.
- **Equity options: a skew** (implied vol *falls* as K rises). The left tail is fat: big crashes are more likely than a lognormal says. Hull gives two reasons:
  - **Leverage:** when a stock falls, the firm's debt-to-equity rises, so its equity gets riskier.
  - **"Crashophobia":** since the 1987 crash, traders pay extra for deep out-of-the-money puts.

**Worked example: build a skew from a crash.** Suppose S_T is lognormal with σ = 20% (S₀ = 100, r = 4%, T = 0.5), except that with **5% probability the stock also drops 30%**. Rescale so that Ê[S_T] = S₀e^{rT} (risk-neutral, Day 21). Price calls by Monte Carlo and back out implied vols:

| K | 80 | 90 | 100 | 110 | 120 |
|---|---|---|---|---|---|
| Call price | 22.06 | 13.58 | 7.05 | 3.03 | 1.09 |
| Implied vol | **23.6%** | 22.3% | 21.5% | 21.1% | **20.9%** |

That's the equity skew. Low strikes (in-the-money calls, or equivalently out-of-the-money puts, by parity) are where the crash matters most. With no crash, every strike gives exactly 20.0%.

**Volatility surface.** Add maturity T as a second axis and you get a table of implied vol by (K, T). Desks keep one surface per underlying and read (or interpolate) the σ for any option from it. The skew is usually steeper for short maturities.

**Code** (the table above):
```python
import numpy as np
from math import log, sqrt, exp, erf
N = lambda x: 0.5*(1 + erf(x/sqrt(2))); S0, r, T = 100, 0.04, 0.5
def bsm(K, sig):                                     # BSM call price
    d1 = (log(S0/K) + (r + sig**2/2)*T)/(sig*sqrt(T)); return S0*N(d1) - K*exp(-r*T)*N(d1 - sig*sqrt(T))
def implied(price, K, lo=0.01, hi=1.0):              # bisection (Day 23)
    for _ in range(60):
        mid = (lo + hi)/2; lo, hi = (mid, hi) if bsm(K, mid) < price else (lo, mid)
    return mid
rng = np.random.default_rng(1); M = 1_000_000
X = 0.20*sqrt(T)*rng.standard_normal(M) + np.where(rng.random(M) < 0.05, -0.30, 0.0)   # 5% chance of a 30% crash
ST = np.exp(X); ST *= S0*exp(r*T)/ST.mean()          # rescale so Ê[S_T] = S0 e^{rT}
for K in (80, 90, 100, 110, 120):
    c = exp(-r*T)*np.maximum(ST - K, 0).mean()       # Monte Carlo call price
    print(K, round(c, 3), f"{implied(c, K):.1%}")    # 80 → 23.6% ... 120 → 20.9%
```

> **Common pitfall.** Thinking the smile means "BSM is useless". Traders still use the BSM *formula* as a translator between prices and vols, just with a different σ per (K, T). What fails is the *assumption* of one constant σ with lognormal S_T. Module I's models (jumps, stochastic vol, local vol) are built to explain the surface.

B confuses the equity skew (vol varies across *strikes*) with a call/put difference at the same strike. C has no basis.
