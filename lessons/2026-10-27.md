### Recall
One step: **f = e^{−rΔt}[p f_u + (1 − p) f_d]** with **p = (e^{rΔt} − d)/(u − d)**. Today we chain that formula: two steps, then any number.

### Today's concept
*Hull: "Binomial Trees" — "Two-Step Binomial Trees", "A Put Example" and "Delta".*

**The tree.** Same stock: S₀ = 100, each 3-month step × 1.1 or × 0.9, r = 4%, Δt = 0.25, so p = **0.5503** and the one-step discount factor is e^{−0.01}. After two steps (6 months):
- up–up: **121**
- up–down or down–up: **99** (the tree "recombines": order doesn't matter)
- down–down: **81**

**Backward induction for a call with K = 100.**
1. *At expiry*: payoffs 21, 0, 0.
2. *Step back to t = 3 months* — each node is a one-step tree:
   - at S = 110: f_u = e^{−0.01}(0.5503 × 21 + 0.4497 × 0) = **11.440**
   - at S = 90: both children pay 0, so f_d = **0**
3. *Step back to today*: f = e^{−0.01}(0.5503 × 11.440 + 0.4497 × 0) = **6.232**.

Shortcut (Hull): f = e^{−2rΔt}[p² f_uu + 2p(1 − p) f_ud + (1 − p)² f_dd]. Check: e^{−0.02} × 0.5503² × 21 = 6.232 ✓.

**Δ changes through the tree.** At each node, Δ = (change in option value)/(change in stock price) over the next step:
- today: Δ = (11.440 − 0)/(110 − 90) = **0.572**
- at S = 110: Δ = (21 − 0)/(121 − 99) = **0.955**
- at S = 90: Δ = (0 − 0)/(99 − 81) = **0**

So a hedger who starts with 0.572 shares per call must **rebalance** after 3 months: buy up to 0.955 shares if the stock rose, or sell down to 0 if it fell. Keeping a hedge riskless means adjusting it as the price moves. This is *dynamic hedging*, and it runs through the rest of the course.

**Code** (any number of steps):
```python
import numpy as np
def tree_price(S0, u, d, K, r, dt, n, kind="call"):
    p = (np.exp(r*dt) - d) / (u - d)                # risk-neutral probability
    j = np.arange(n + 1)                            # number of down moves at expiry
    S = S0 * u**(n - j) * d**j                      # stock prices at expiry, highest first
    f = np.maximum(S - K, 0) if kind == "call" else np.maximum(K - S, 0)
    for _ in range(n):                              # step back one period at a time
        f = np.exp(-r*dt) * (p*f[:-1] + (1-p)*f[1:])   # neighbours = up/down children
    return f[0]
print(tree_price(100, 1.1, 0.9, 100, 0.04, 0.25, 2))          # 6.2324
print(tree_price(100, 1.1, 0.9, 100, 0.04, 0.25, 2, "put"))   # 4.2523
```

> **Common pitfall.** Using a single Δ for the whole life of the option. Δ is node-specific: it depends on where the stock is *now* and how much time is left. A hedge set at t = 0 is only riskless until the next move.
