### Today's concept: probability spaces, σ-algebras as information, filtrations

**Why a quant cares.** Every hedge, every price and every "conditional on what we know at time t" statement needs a precise meaning of "what is known at time t". A hedge ratio chosen at t may depend only on information up to t. Filtrations formalise this, and the whole Itô-integral machinery later rests on it.

**Probability space (Ω, F, P).**
- Ω: the set of all possible "worlds" (here: the 8 toss sequences ω = ω₁ω₂ω₃).
- F: a σ-algebra of events (subsets of Ω) — contains Ω, closed under complements and countable unions. These are the questions we're allowed to ask.
- P: a probability measure on F, with P(Ω) = 1 and countable additivity. Here P(ω) = p^(#H)·(1−p)^(#T).

**σ-algebra = information.** After seeing the first n tosses, you can answer exactly the yes/no questions that are unions of "atoms" — groups of outcomes sharing the same first n tosses. Call this σ-algebra Fₙ.
- F₀ = {∅, Ω}: nothing known (1 atom).
- F₁: atoms H**, T** — 2 atoms, so 2² = 4 events.
- F₂: atoms HH*, HT*, TH*, TT* — 4 atoms, so 2⁴ = 16 events.
- F₃ = all 2⁸ = 256 subsets of Ω: everything is revealed.

**Filtration** (Fₙ) is an increasing family F₀ ⊂ F₁ ⊂ F₂ ⊂ F₃: information is never forgotten.

**Measurability.** X is Fₙ-measurable if its value is determined by the information in Fₙ, i.e. X is constant on each Fₙ-atom. A process (Xₙ) is **adapted** if Xₙ is Fₙ-measurable for every n. The price Sₙ is adapted. S₃ is not F₂-measurable: the atom HH* contains both S₃ = 133.1 and S₃ = 108.9.

**Worked example.** A = {S₂ = 99}. S₂ = 99 exactly when the first two tosses are HT or TH, so A = HT* ∪ TH*, a union of two F₂ atoms. Hence A ∈ F₂ and P(A) = 2·0.6·0.4 = 0.48. But A ∉ F₁: knowing only the first toss (say H) you can't tell whether S₂ = 99 or 121.

**Code** (an event is in Fₙ iff it is a union of Fₙ atoms):
```python
import itertools, numpy as np
S0, u, d, p = 100, 1.1, 0.9, 0.6
Omega = list(itertools.product("HT", repeat=3))
P = {w: np.prod([p if x == "H" else 1-p for x in w]) for w in Omega}
S = lambda w, n: S0*np.prod([u if x == "H" else d for x in w[:n]])
atoms = lambda n: {a: [w for w in Omega if w[:n] == a] for a in itertools.product("HT", repeat=n)}
def in_F(event, n):
    return all(set(a) <= event or not set(a) & event for a in atoms(n).values())
A = {w for w in Omega if abs(S(w, 2) - 99) < 1e-9}
print(len(atoms(2)), in_F(A, 1), in_F(A, 2), sum(P[w] for w in A))   # 4 False True 0.48
```

> **Common pitfall.** Thinking a σ-algebra is "the set of outcomes you know". It is the set of *questions you can answer*. Also: an event can have a probability without being "known" at time n — P(S₃ > 100) is perfectly well defined today, but whether it happens isn't decided until time 3.

## Solutions

**Q1: A.** S₁ depends only on the first toss. B (S₂) depends on two tosses. C depends on toss 2, which is unknown at time 1 (the event splits each F₁ atom). D = S₃ − S₂ depends on toss 3.

**Q2.** (a) Atoms: HH*, HT*, TH*, TT*; |F₂| = 2⁴ = 16. (b) S₂ = 121 iff HH, so B = HH*, P(B) = 0.36. (c) B ∉ F₁: the atom H** contains HH* ⊂ B and HT* ⊄ B, so B is not a union of F₁ atoms.

**Q3.** (i) P(S₃ > 100) = P(≥ 2 heads) = 0.6³ + 3·0.6²·0.4 = 0.648. (ii) Given H, need at least one more head in two tosses: 1 − 0.4² = 0.84. E[S₃] = 100·(0.6·1.1 + 0.4·0.9)³ = 100·1.02³ = 106.1208 (matches exactly, because the tosses are independent and E[per-step factor] = 1.02).
