### Today's concept
*Hull: "The Black–Scholes–Merton Model" — "Derivation of the Black–Scholes–Merton Differential Equation" (second half), including the forward-contract example.*

**Step 4 — Riskless means it earns r.** No-arbitrage (Day 4): a riskless portfolio must earn exactly the risk-free rate, so ΔΠ = rΠΔt. Substitute both sides:
  (−∂f/∂t − ½ ∂²f/∂S² σ²S²)Δt = r(−f + ∂f/∂S · S)Δt.
Rearrange to get **the Black–Scholes–Merton differential equation**:

  **∂f/∂t + rS ∂f/∂S + ½σ²S² ∂²f/∂S² = r f**

**What it says.**
- *Every* derivative on a non-dividend stock (call, put, forward, anything) satisfies this same equation.
- **μ is not in it.** Only r and σ appear, which is why tomorrow we can price "as if" the stock earns r: risk-neutral valuation again (Day 5), now in continuous time.
- What makes one derivative different from another is its **boundary condition**: the payoff at expiry.
  - European call: f = max(S − K, 0) at t = T
  - European put: f = max(K − S, 0) at t = T

**Check it on a forward contract (Hull's example).** A long forward with delivery price K is worth f = S − Ke^{−r(T−t)}.
- ∂f/∂t = −rKe^{−r(T−t)}, ∂f/∂S = 1, ∂²f/∂S² = 0.
- Left side: −rKe^{−r(T−t)} + rS·1 + 0 = r(S − Ke^{−r(T−t)}) = **r f** ✓.

**A failure.** f = S² does **not** satisfy the equation: the left side minus rf is (r + σ²)S² ≠ 0. A contract paying S² *now* isn't a self-consistent price. But **f = e^{(r+σ²)(T−t)} S²**, the value today of receiving S_T² at T, does satisfy it. Q2 asks you to show this.

**Code** (check any candidate price with finite differences):
```python
import numpy as np
r, sigma, T, K = 0.04, 0.2, 1.0, 100
def bsm_residual(f, S, t, h=1e-3, k=1e-5):
    fS  = (f(S+h, t) - f(S-h, t)) / (2*h)              # ∂f/∂S
    fSS = (f(S+h, t) - 2*f(S, t) + f(S-h, t)) / h**2   # ∂²f/∂S²
    ft  = (f(S, t+k) - f(S, t-k)) / (2*k)              # ∂f/∂t
    return ft + r*S*fS + 0.5*sigma**2*S**2*fSS - r*f(S, t)   # 0 if f solves BSM
forward = lambda S, t: S - K*np.exp(-r*(T - t))
print(bsm_residual(forward, 100.0, 0.0))               # ≈ 0 ✓
```

> **Common pitfall.** Thinking the BSM equation *is* the option price. It's an equation every derivative price must satisfy. You only get a specific price (the famous formula, tomorrow) once you add that derivative's boundary condition.
