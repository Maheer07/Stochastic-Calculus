### Recall
E[S_T] = S₀e^{μT} is a forecast made **today**, at time 0. But a trader re-forecasts every day as prices move. Today: forecasting *given what we know now*, and the special case where the best forecast is "no change".

### Today's concept
*Hull: "Martingales and Measures" — the opening section "Martingales" (a preview; we return to it in Module F); "Interest Rates" — continuous compounding for discounting.*

We go back to Day 1's tree: S₀ = 100, each step × u = 1.1 (prob p = 0.6) or × d = 0.9 (prob 0.4).

**Expectation given today's information.** Write E_t[X] for "the best forecast of X using everything known at time t". After one step you know S₁, so:
- If S₁ = 110: E₁[S₂] = 110 × (0.6 × 1.1 + 0.4 × 0.9) = 110 × 1.02 = **112.2**
- If S₁ = 90: E₁[S₂] = 90 × 1.02 = **91.8**

Before step 1, E₁[S₂] is itself random: 112.2 or 91.8.

**Two rules you'll use constantly.**
1. *What's known comes out:* E₁[S₁ × Y] = S₁ × E₁[Y], because S₁ is just a number at time 1.
2. *A forecast of a forecast is today's forecast:* E₀[E₁[S₂]] = E₀[S₂]. Check: 0.6 × 112.2 + 0.4 × 91.8 = **104.04** = 100 × 1.02² ✓.

**Fair game = martingale.** A process X is a **martingale** if its best forecast of any future value is today's value: E_t[X_T] = X_t. A fair coin game (win or lose $1 each toss) is a martingale: on average you don't drift up or down. Our stock is **not** one: it drifts up 2% per step.

**Discounting.** Money at time T is worth less today: a payoff X at T is worth e^{−rT}X today (reminder: e^{−rT} undoes continuous growth at rate r). So it's natural to look at the *discounted* price e^{−rt}S_t. Is that fair?

Say each step's interest growth is e^{rΔt} = 1.01. The discounted forecast is E₀[S₁]/1.01 = 102/1.01 = 100.99 > 100. Not fair: the stock beats the bank on average, which is exactly why people hold stocks.

**Preview of a big idea.** Suppose we swapped the real p = 0.6 for a made-up p* chosen so that the discounted price *is* fair:
  p* × 1.1 + (1 − p*) × 0.9 = 1.01 → **p* = (1.01 − 0.9)/(1.1 − 0.9) = 0.55**.
Hull calls this the **risk-neutral probability**, p = (e^{rΔt} − d)/(u − d). On Day 5 we'll see why option prices use p*, not the real p.

**Code** (check the forecasts and find p*):
```python
import numpy as np
u, d, p = 1.1, 0.9, 0.6
growth = p*u + (1-p)*d                    # expected growth per step = 1.02
print(110*growth, 90*growth)              # E1[S2] in each state: 112.2  91.8
print(p*110*growth + (1-p)*90*growth)     # forecast of the forecast = 104.04
bank = 1.01                               # interest growth per step, e^{rΔt}
p_star = (bank - d) / (u - d)             # makes E*[S1]/bank = S0
print(p_star, (p_star*110 + (1-p_star)*90) / bank)   # 0.55  100.0
```

> **Common pitfall.** Thinking "martingale" means "random walk with no trend in prices". It's about **forecasts**: X is a martingale if E_t[X_T] = X_t. A stock can be a martingale under one set of probabilities (p* = 0.55, after discounting) and not under another (the real p = 0.6). Which probabilities you use matters.

## Solutions

**Q1: A (91.8)** = 90 × (0.6 × 1.1 + 0.4 × 0.9) = 90 × 1.02. B (90) would be right only if the stock were a martingale (it drifts up). C (99) is the up-move value 90 × 1.1, not the average. D (104.04) is E₀[S₂], the forecast made *before* step 1, which ignores that step 1 went down.

**Q2.** (a) Future tosses average zero, so E₁[X₃] = X₁ = **1**. (b) **Yes**: E_n[X_{n+1}] = X_n + ½(1) + ½(−1) = X_n. (c) X₂ = 2 or 0, each with probability ½, so E₁[Y₂] = ½ × 4 + ½ × 0 = **2 ≠ 1**. **Not** a martingale: Y drifts up by 1 per toss (in general E_n[Y_{n+1}] = Y_n + 1). So X_n² − n *is* a martingale. Keep this in mind: we meet the same fact for the Wiener process, where z² − t is fair.

**Q3.** (a) Real p: 0.6 × 10 / 1.01 = **5.94**. (b) p*: 0.55 × 10 / 1.01 = **5.45**. The right price is **5.45**. On Day 5 we show that 5.45 is the cost of a stock-plus-bank portfolio that copies the option exactly. Any other price gives an arbitrage, whatever the real p.
