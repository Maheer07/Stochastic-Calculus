### Today's concept
*Hull: "Wiener Processes and Itô's Lemma" — "Wiener Process".*

**Definition (Hull).** A variable z follows a **Wiener process** if:
1. Over a small interval Δt, its change is **Δz = ε√Δt**, where ε ~ φ(0, 1).
2. Changes Δz over any two **non-overlapping** short intervals are **independent**.

Property 2 makes z Markov. Property 1 fixes the size of the moves.

**What follows.** Over a longer period T, split into N = T/Δt steps:
  z(T) − z(0) = ε₁√Δt + ε₂√Δt + … + ε_N√Δt.
- Mean: **0**
- Variance: N × Δt = **T**; st. dev. **√T**
- Distribution: **φ(0, T)** (a sum of independent normals is normal)

*Example:* z(0) = 10. After 4 years z ~ φ(10, 4) (st. dev. 2). After 9 months, z ~ φ(10, 0.75) (st. dev. 0.866).

**Notation.** As Δt → 0, Hull writes **dz = ε√dt**. This "dz" is shorthand for "the Δz-rule with a tiny Δt". It's what appears in dS = μS dt + σS dz on Wednesday.

**Two strange facts.** Zoom in on any piece of a Wiener path and it stays just as jagged.
- *The path length is infinite.* Each step's expected size is E|Δz| = √(2Δt/π). Over 1 year, N steps give total expected length N√(2Δt/π) = √(2N/π), which grows without bound: **8.0** (N = 100), **25.2** (N = 1,000), **79.8** (N = 10,000)…
- *The path has no slope anywhere.* Δz/Δt = ε/√Δt blows up as Δt → 0. That's why ordinary calculus fails for z, and why we need Itô's lemma (coming on Friday).

**Code:**
```python
import numpy as np
rng = np.random.default_rng(42)
n = 252; dt = 1/n                                   # daily steps over 1 year
dz = rng.standard_normal((10_000, n)) * np.sqrt(dt) # property 1: Δz = ε√Δt, independent
z = dz.cumsum(axis=1)                               # z(t), starting from z(0) = 0
print(z[:, -1].mean(), z[:, -1].var())              # ≈ 0, ≈ 1  → z(1) ~ φ(0, 1)
print(np.abs(dz).sum(axis=1).mean())                # average path length ≈ √(2n/π) = 12.67
# Plot a few paths: import matplotlib.pyplot as plt; plt.plot(z[:5].T); plt.show()
```

> **Common pitfall.** Writing Δz = εΔt (forgetting the square root). That makes the variance over T equal to TΔt, which vanishes as Δt → 0: no randomness left. The √Δt is the whole point.
