### Today's concept
*Hull: "The Greek Letters" — "Hedging in Practice", "Scenario Analysis" and "Extension of Formulas".*

**Hedging in practice.** A desk with thousands of options can't trade options every hour: they're costly to trade and may not be available at good prices. Hull describes what traders actually do:
- **Delta:** made zero (or close) **at least once a day**, using the underlying. Shares and futures are cheap to trade.
- **Gamma and vega:** **monitored**. When they get too big, the trader fixes them when a good opportunity arises.
- **Size helps.** One option is expensive to hedge. A big book's options partly offset each other, so the fixed cost of hedging is spread across many trades.

**Scenario analysis.** The Greeks are *local*: a Taylor expansion, ΔΠ ≈ Δ·ΔS + ½Γ(ΔS)² + ν·Δσ, is only good for small moves. So risk managers also **fully reprice** the book on a grid of scenarios (stock price × volatility) and read off the P&L in each cell. Nothing is approximated, and big moves get tested properly.

**Worked example.** Our book: short 10,000 calls (K = 105, T = 0.75; S = 100, r = 4%, σ = 25%). Instant P&L ($) after the move:

Read the first grid:
- **Down the middle column** is vega: σ up 5 points costs ≈ 5 × 3,454 = 17,270 ✓.
- **Along the middle row** is short gamma: every big move loses money, about ½ × 184 × 10² ≈ 9,200 for ±$10 (−9,385 and −8,748).

The full hedge shrinks the worst cell from −26k to under −1k. What's left comes from effects the three Greeks don't capture: delta changes when σ moves, and vega changes when S moves.

**Module D in one table** (our call; per 1 option):

| Greek | Meaning | Formula (call) | Value |
|---|---|---|---|
| Δ | ∂c/∂S | N(d₁) | 0.509 |
| Γ | ∂²c/∂S² | N′(d₁)/(Sσ√T) | 0.0184 |
| Θ | ∂c/∂t | −SN′(d₁)σ/(2√T) − rKe^{−rT}N(d₂) | −7.48/yr |
| ν | ∂c/∂σ | S√T N′(d₁) | 34.5 |
| ρ | ∂c/∂r | KTe^{−rT}N(d₂) | 32.3 |

Glue: **Θ + rSΔ + ½σ²S²Γ = rΠ**. Shares fix Δ only; options fix Γ and ν.

**Code** (the scenario grid by full revaluation):
```python
import numpy as np
from math import log, sqrt, exp, erf
N = lambda x: 0.5*(1 + erf(x/sqrt(2))); r = 0.04
def call(S, K, T, sig):                             # BSM call price
    d1 = (log(S/K) + (r + sig**2/2)*T)/(sig*sqrt(T))
    return S*N(d1) - K*exp(-r*T)*N(d1 - sig*sqrt(T))
def book(S, sig, wA=0.0, wB=0.0, sh=5085.6):        # default = delta-hedged only
    return (-10_000*call(S, 105, 0.75, sig) + wA*call(S, 100, 0.25, sig)
            + wB*call(S, 110, 1.0, sig) + sh*S)
v0 = book(100, 0.25)                                # value today
for sig in (0.20, 0.25, 0.30):                      # one row per vol scenario
    print(sig, [round(book(S, sig) - v0) for S in (90, 95, 100, 105, 110)])
# row 0.30 ends ... -25987: vol up + big move is the worst case
```

> **Common pitfall.** Trusting the Greeks for big moves. They are slopes at today's point. For a $10 move, or a jump in vol, reprice the whole book. That is why banks report scenario grids (and stress tests) alongside the Greeks.
