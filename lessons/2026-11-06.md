### Today's concept
*Hull: "Wiener Processes and Itô's Lemma" — "Itô's Lemma" and the chapter appendix "A Nonrigorous Derivation of Itô's Lemma".*

**Two calculus tools (quick primer).**
- **Partial derivative.** For G(S, t), ∂G/∂S is the slope in S with t held fixed; ∂G/∂t is the slope in t with S held fixed. Example: G = S²t gives ∂G/∂S = 2St, ∂²G/∂S² = 2t, ∂G/∂t = S².
- **Taylor expansion.** A small change in a smooth function: f(x + Δx) ≈ f(x) + f′(x)Δx + ½f″(x)Δx² + … Example: f(x) = x² at x = 3, Δx = 0.1 gives 9 + 6(0.1) + ½·2·(0.1)² = 9.61, exactly 3.1². Usually you keep only the first-order terms, because Δx² is tiny.

**Derivation (Hull's appendix, in 4 lines).** Let x follow dx = a dt + b dz, and G = G(x, t). Taylor-expand:
  ΔG ≈ (∂G/∂x)Δx + (∂G/∂t)Δt + ½(∂²G/∂x²)Δx² + (terms that vanish)
1. Δx = aΔt + bε√Δt.
2. Δx² = b²ε²Δt + (terms in Δt^{3/2} and Δt², which vanish) → **b² dt** (yesterday's rule).
3. So the ½(∂²G/∂x²)Δx² term does *not* vanish: it becomes ½(∂²G/∂x²) b² dt.
4. Collect the dt and dz terms:

  **dG = ( ∂G/∂x · a + ∂G/∂t + ½ ∂²G/∂x² · b² ) dt + ∂G/∂x · b dz**

That's **Itô's lemma**. It's the ordinary chain rule *plus one extra term*, ½ ∂²G/∂x² · b² dt, which comes straight from (dz)² = dt.

**For a stock** (a = μS, b = σS):

  **dG = ( ∂G/∂S · μS + ∂G/∂t + ½ ∂²G/∂S² · σ²S² ) dt + ∂G/∂S · σS dz**

G is also driven by the *same* dz as S. That shared randomness is what lets a hedger cancel it, which is the key to Black–Scholes in Module C.

**Check 1 — yesterday's puzzle.** G = z² (a = 0, b = 1): ∂G/∂z = 2z, ∂²G/∂z² = 2. Itô gives dG = (0 + 0 + ½·2·1) dt + 2z dz = **dt + 2z dz** ✓.

**Check 2 — the −σ²/2, finally.** G = ln S: ∂G/∂S = 1/S, ∂²G/∂S² = −1/S², ∂G/∂t = 0. Itô gives
  dG = (μ − ½σ²) dt + σ dz.
So ln S is a generalized Wiener process with drift μ − σ²/2 and volatility σ. Over T (Day 11), **ln S_T − ln S₀ ~ φ[(μ − σ²/2)T, σ²T]**: exactly Day 2's lognormal result, now derived. The −σ²/2 *is* the Itô term. (Monday applies this further.)

**Code** (check d(ln S) numerically by simulating dS directly):
```python
import numpy as np
rng = np.random.default_rng(42)
n = 252; dt = 1/n; mu, sigma = 0.08, 0.2
S = np.full(100_000, 100.0)
for _ in range(n):                                 # simulate dS = μS dt + σS dz (no Itô used)
    S = S * (1 + mu*dt + sigma*np.sqrt(dt)*rng.standard_normal(100_000))
L = np.log(S / 100)
print(L.mean(), L.std())        # ≈ 0.060 = μ − σ²/2, and ≈ 0.200 = σ — Itô's prediction
```

> **Common pitfall.** Applying the ordinary chain rule, d(ln S) = dS/S = μ dt + σ dz, and concluding the log return drifts at μ. That drops the ½ ∂²G/∂S² σ²S² term. Whenever G is curved in S (∂²G/∂S² ≠ 0), the Itô term is there.
