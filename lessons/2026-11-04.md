### Recall
An Itô process is dx = a(x, t) dt + b(x, t) dz: a drift and a noise term that can depend on where x is now. Today we choose a and b for a stock, and get the model behind Black–Scholes.

### Today's concept
*Hull: "Wiener Processes and Itô's Lemma" — "The Process for a Stock Price", "Discrete-Time Model" and "Monte Carlo Simulation".*

**Why not dS = a dt + b dz?** A constant drift a would mean a $10 stock and a $100 stock both rise by the same $ amount each year. But investors want the same *percentage* return whatever the price. So the drift should be μS, and likewise the noise σS: a 2% daily move is "normal" whether the stock is at 10 or 100. That gives Hull's model:

  **dS = μS dt + σS dz**, or equivalently **dS/S = μ dt + σ dz**.

- **μ** = expected return per year (continuously compounded); **σ** = volatility per year.
- If σ = 0: dS/S = μ dt → **S_T = S₀e^{μT}**, steady growth at rate μ (a reminder of Day 2).
- This process is called *geometric Brownian motion* (GBM).

**Discrete-time model.** Over a small step Δt:
  **ΔS/S = μΔt + σε√Δt**, with ε ~ φ(0, 1),
so the percentage return over Δt is ~ φ(μΔt, σ²Δt).

*Example* (running numbers μ = 0.08, σ = 0.2, weekly Δt = 1/52):
- ΔS/S = 0.00154 + 0.0277ε: mean +0.15% a week, st. dev. **2.77%** a week (Day 9's scaling).
- At S = 100: ΔS ~ φ(0.154, 2.774²).
- The weekly drift is about 1/18 of the weekly noise. On a typical week, randomness dominates.

**Monte Carlo simulation** (Hull's spreadsheet idea): draw an ε, update S ← S(1 + μΔt + σε√Δt), and repeat. One run gives one possible path; thousands of runs give the distribution of S_T.

**Code:**
```python
import numpy as np
S0, mu, sigma, T, n = 100, 0.08, 0.2, 1.0, 52      # weekly steps for 1 year
dt = T / n
rng = np.random.default_rng(42)
S = np.full(10_000, float(S0))                     # 10,000 paths, all start at 100
for _ in range(n):
    eps = rng.standard_normal(10_000)
    S = S * (1 + mu*dt + sigma*np.sqrt(dt)*eps)    # ΔS/S = μΔt + σε√Δt
print(S.mean(), np.median(S))                      # ≈ 108.3 and ≈ 106.0
```

Compare with Day 2: the mean is S₀e^{μT} = **108.33** and the median is S₀e^{(μ − σ²/2)T} = **106.18**. The step-by-step model reproduces the lognormal facts. On Friday, Itô's lemma will show *why* the −σ²/2 appears.

> **Common pitfall.** Reading μ as the expected *log* return. μ is the expected return of dS/S over a tiny interval. The expected log return per year is μ − σ²/2 (6% here, not 8%). That's the volatility drag from Day 2, and Itô's lemma explains it formally.
