# Week 3 Recap — 2026-11-06 (Days 10–14)

## This week in one paragraph
This was the week stochastic calculus proper began. Monday named the limit of last week's random walk: the **Wiener process**, with Δz = ε√Δt and independent increments, so z(T) − z(0) ~ φ(0, T). Its paths are infinitely long and have no slope. Tuesday added drift and scale (**dx = a dt + b dz**) and then let them depend on x and t (**Itô processes**). Wednesday chose a = μS and b = σS to get Hull's stock model **dS = μS dt + σS dz**, and a Monte Carlo simulation matched Day 2's lognormal mean and median. Thursday found the surprise that makes everything work: **(Δz)² behaves like Δt**, so dz·dz = dt while dt·dt = dt·dz = 0. Friday turned that into **Itô's lemma**, and used it to *derive* d(ln S) = (μ − σ²/2) dt + σ dz, explaining the −σ²/2 we'd been carrying since Day 2.

## Day by day
**Day 10 — The Wiener process** (Mon)
- Δz = ε√Δt with ε ~ φ(0, 1); changes over non-overlapping intervals are independent.
- z(T) − z(0) ~ φ(0, T): mean 0, variance T.
- Expected path length √(2N/π) → ∞; no slope anywhere (Δz/Δt = ε/√Δt).
- Python idea: cumulative sums of ε√Δt; check mean, variance and path length.

**Day 11 — Generalized Wiener & Itô processes** (Tue)
- dx = a dt + b dz ⇒ x(T) − x(0) ~ φ(aT, b²T).
- Drift grows like T, noise like √T: short horizons look like pure noise.
- Itô process: dx = a(x, t) dt + b(x, t) dz, simulated step by step (e.g. mean reversion a = κ(θ − x)).
- Python idea: loop Δx = a(x)Δt + bε√Δt, updating x each step.

**Day 12 — The process for a stock price** (Wed)
- dS = μS dt + σS dz (same % drift and % noise at any price).
- Discrete model: ΔS/S = μΔt + σε√Δt; weekly, our stock moves 0.15% ± 2.77%.
- Monte Carlo: mean ≈ S₀e^{μT}, median ≈ S₀e^{(μ − σ²/2)T}.
- Python idea: S ← S(1 + μΔt + σε√Δt) for 10,000 paths.

**Day 13 — Why (Δz)² behaves like Δt** (Thu)
- (Δz)² = ε²Δt has mean Δt and variance 2Δt², so Σ(Δz)² → T exactly.
- Multiplication table: dt·dt = 0, dt·dz = 0, **dz·dz = dt**.
- d(z²) = 2z dz + dt, so E[z(T)²] = T.
- Python idea: Σ(Δz)² for finer and finer steps; its spread → 0.

**Day 14 — Itô's lemma** (Fri)
- Taylor-expand G(x, t) and keep ½ ∂²G/∂x² (Δx)² → ½ ∂²G/∂x² b² dt.
- dG = (∂G/∂S μS + ∂G/∂t + ½ ∂²G/∂S² σ²S²) dt + ∂G/∂S σS dz.
- G = ln S ⇒ d(ln S) = (μ − σ²/2) dt + σ dz ⇒ the lognormal law.
- G = S² ⇒ E[S_T²] = S₀²e^{(2μ+σ²)T} (simulation confirms; ordinary calculus is ~30 standard errors off).

## Formula sheet
- Wiener process: Δz = ε√Δt; z(T) − z(0) ~ φ(0, T)
- Generalized Wiener: dx = a dt + b dz; x(T) − x(0) ~ φ(aT, b²T)
- Itô process: dx = a(x, t) dt + b(x, t) dz
- Stock: dS = μS dt + σS dz; ΔS/S ~ φ(μΔt, σ²Δt)
- Multiplication table: dt² = 0, dt·dz = 0, dz² = dt
- Itô's lemma (stock): dG = (G_S μS + G_t + ½ G_SS σ²S²) dt + G_S σS dz
- d(ln S) = (μ − σ²/2) dt + σ dz ⇒ ln S_T ~ φ[ln S₀ + (μ − σ²/2)T, σ²T]
- d(S²) = (2μ + σ²)S² dt + 2σS² dz

## Solutions

**WC1: A (φ(8, 64)).** Mean 20 − 3 × 4 = 8; variance 4² × 4 = 64. B forgets to multiply b² by T. C drops the (negative) drift. D uses the st. dev. 8 as the variance.

**WC2.** (a) ∂G/∂S = **−1/S²**, ∂²G/∂S² = **2/S³**, ∂G/∂t = 0. (b) dG = (−1/S² · μS + ½ · 2/S³ · σ²S²) dt + (−1/S²) σS dz = (−μ + σ²)(1/S) dt − σ(1/S) dz = **(σ² − μ)G dt − σG dz** ✓. (c) E[1/S_T] = 0.01 × e^{0.04 − 0.08} = **0.009608**. Naive 1/E[S_T] = 1/108.33 = 0.009231: about 4% too low. (Jensen's effect: the average of 1/S is above 1/(average S).)

**WC3.** Seed 42: average 1/S_T ≈ **0.009606 ± 0.000006**, matching Itô's **0.009608**. The ordinary-calculus answer 0.01 × e^{−0.08} = **0.009231** is about 60 standard errors away.
