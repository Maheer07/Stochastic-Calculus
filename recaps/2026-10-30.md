# Week 2 Recap — 2026-10-30 (Days 5–9)

## This week in one paragraph
Week 1 ended with a riskless-portfolio price that matched a mysterious probability p. On Monday we proved they always agree: **price = e^{−rT} × expected payoff under p**, in a "risk-neutral world" where every asset earns r and μ drops out. Tuesday chained that one-step rule backwards through two-step trees and showed that Δ changes from node to node, so hedges must be rebalanced. Wednesday added American options (check early exercise at every node) and tied the tree to a real volatility with u = e^{σ√Δt}. With enough steps, prices converge to Black–Scholes. Thursday looked at the tree as Δt → 0: ln S becomes a random walk with steps of size √Δt. Friday opened Module B with the two ideas behind that: the **Markov property** (only today's value matters) and **variances add**, so uncertainty grows like √time. Next week we name the limit, the **Wiener process**, and build dS = μS dt + σS dz from it.

## Day by day
**Day 5 — Risk-neutral valuation** (Mon)
- f = e^{−rT}[p f_u + (1 − p) f_d], p = (e^{rT} − d)/(u − d).
- Under p the stock earns r: the risk-neutral world. μ never enters, because the hedge uses only u, d and r.
- In the real world the option would need its own, much higher discount rate (38.6% in our example). That rate is unknowable in advance, which is why we price risk-neutrally.
- Python idea: `rn_price()`, a one-line risk-neutral pricer.

**Day 6 — Two-step trees** (Tue)
- Backward induction: payoffs at expiry → one-step formula at each earlier node → today.
- Shortcut: f = e^{−2rΔt}[p² f_uu + 2p(1 − p) f_ud + (1 − p)² f_dd].
- Δ changes through the tree (0.572 → 0.955 or 0): dynamic hedging.
- Python idea: `tree_price()` for any number of steps.

**Day 7 — American options; matching volatility** (Wed)
- u = e^{σ√Δt}, d = 1/u.
- American: node value = max(continuation, exercise now), checked at every node.
- American puts can be worth exercising early. American calls on non-dividend stocks never are.
- More steps → convergence to Black–Scholes (European put 4.006 → 4.647).
- Python idea: add `np.maximum(f, payoff(S))` inside the backward loop.

**Day 8 — From trees to continuous time** (Thu)
- In log space each step is ±σ√Δt: ln S is a random walk.
- As n → ∞: p → ½, mean → (r − σ²/2)T, st. dev. → σ√T, and the distribution → normal.
- Steps must scale with √Δt to keep the randomness alive.
- Python idea: simulate tree endpoints with `rng.binomial`, then price by Monte Carlo (9.925 ≈ BS).

**Day 9 — Markov property; continuous-time processes** (Fri)
- Markov: the future depends only on the present value. Linked to weak-form market efficiency.
- Independent changes → variances add → over Δt the change is φ(0, Δt), st. dev. √Δt.
- Scaling volatility: σ_daily = σ_annual / √252.
- Python idea: cumulative sums of φ(0, Δt) steps; check √t scaling and zero step-to-step correlation.

## Formula sheet
- Risk-neutral valuation (one step): f = e^{−rΔt}[p f_u + (1 − p) f_d], p = (e^{rΔt} − d)/(u − d)
- Two steps: f = e^{−2rΔt}[p² f_uu + 2p(1 − p) f_ud + (1 − p)² f_dd]
- Δ at a node = (f_up − f_down)/(S_up − S_down)
- Volatility matching: u = e^{σ√Δt}, d = 1/u
- American option node: f = max(e^{−rΔt}[p f_u + (1 − p) f_d], exercise value)
- Tree limit: ln(S_T/S₀) → φ[(r − σ²/2)T, σ²T] under risk-neutral p
- Markov variance scaling: change over Δt ~ φ(0, σ²Δt); σ_period = σ_annual × √(period in years)

## Solutions

**WC1: A (8.3%).** 0.3 × √(1/13) = 0.0832. B divides by 13 instead of √13 (scaling st. dev. with time instead of variance). C ignores the horizon. D uses √(1/4).

**WC2.** (a) u = e^{0.3√0.5} = e^{0.2121} = **1.2363**, d = **0.8089**, p = (e^{0.025} − 0.8089)/(1.2363 − 0.8089) = **0.5064**. (b) Expiry prices 76.42, 50.00, 32.71 → put payoffs 0, 2, 19.29. At S = 61.82: continuation e^{−0.025}(0.5064 × 0 + 0.4936 × 2) = **0.963**; exercise = 0 → hold. At S = 40.44: continuation e^{−0.025}(0.5064 × 2 + 0.4936 × 19.29) = 10.27; exercise = 52 − 40.44 = **11.56** → exercise early. Today: continuation e^{−0.025}(0.5064 × 0.963 + 0.4936 × 11.56) = **6.039**; exercise = 2 → hold. **American put = 6.039.** (c) Premium = 6.039 − 5.421 = **0.618**.

**WC3.** n = 10: **9.729**; 11: **10.092**; 50: **9.885**; 51: **9.961**; 200: **9.915**; 201: **9.934**. Even n undershoots and odd n overshoots (for this at-the-money strike), and the gap shrinks as n grows. The tree price oscillates around 9.925 while converging. A common practical fix is to average the n and n + 1 prices: (9.915 + 9.934)/2 = 9.925.
