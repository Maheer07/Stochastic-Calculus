# Week 4 Recap — 2026-11-13 (Days 15–19)

## This week in one paragraph
We put Itô's lemma to work, then crossed into Module C. Monday applied it to Hull's own examples: the forward price follows **dF = (μ − r)F dt + σF dz** (no Itô correction, since F is linear in S), and ln S gives the lognormal law, with confidence intervals built on the log scale. Tuesday added a second source of randomness: **dz₁dz₂ = ρ dt**, Hull's recipe for correlated shocks, and a cross term in Itô's lemma. Then we reviewed Module B. Wednesday opened *The Black–Scholes–Merton Model*: the realized return x ~ φ(μ − σ²/2, σ²/T), and the difference between the arithmetic μ and the compound μ − σ²/2. Thursday estimated σ from data (log returns, ×√252, standard error σ̂/√(2n)). Friday began the main event: **short 1 derivative, long ∂f/∂S shares**, and both the dz *and* the μ terms cancel, leaving a riskless ΔΠ. Monday turns that into the BSM equation.

## Day by day
**Day 15 — Applications of Itô's lemma** (Mon)
- F = Se^{r(T−t)} ⇒ dF = (μ − r)F dt + σF dz: same σ, drift μ − r.
- d(ln S) = (μ − σ²/2) dt + σ dz ⇒ ln S_T ~ φ[ln S₀ + (μ − σ²/2)T, σ²T].
- Example (T = 0.5): 95% interval 78.10 to 135.96; P(S_T > 110) = 32.2%.
- Discounted price Se^{−rt} has drift μ − r: a martingale exactly when μ = r.

**Day 16 — Correlated processes; Module B review** (Tue)
- dz₁dz₂ = ρ dt; simulate with ε₂ = ρu + √(1 − ρ²)v.
- Two-variable Itô adds the cross term G₁₂ b₁b₂ρ dt.
- Foreign stock in pounds: drift μ₁ + μ₂ + ρσ₁σ₂ = 9.4%; vol √(σ₁² + σ₂² + 2ρσ₁σ₂) = 19.5%.
- Module B in six lines: Markov → Wiener → Itô process → stock model → (dz)² = dt → Itô's lemma.

**Day 17 — The distribution of the rate of return** (Wed)
- x = (1/T) ln(S_T/S₀) ~ φ(μ − σ²/2, σ²/T): it settles down as T grows.
- μ = short-period (arithmetic) expected return; μ − σ²/2 = compound (geometric) growth.
- Fund example: an arithmetic 5.0% compounds to only 4.4%.

**Day 18 — Estimating volatility** (Thu)
- uᵢ = ln(Sᵢ/Sᵢ₋₁); σ̂ = s/√τ (daily: ×√252); standard error ≈ σ̂/√(2n).
- 10-day example: 19.8% ± 4.4%. A true 20% estimated from 1 month / 1 year / 5 years: 17.0% / 18.8% / 19.8%.
- Use trading days (252), and 90–180 days of data or the option's life.

**Day 19 — BSM equation, part 1: the riskless portfolio** (Fri)
- ΔS and Δf share the same Δz (Itô).
- Π = −f + (∂f/∂S)S ⇒ **ΔΠ = (−∂f/∂t − ½ ∂²f/∂S² σ²S²)Δt**: no Δz, no μ.
- f = S² demo: daily hedging cuts risk ~111×, weekly only ~50×. Continuous rebalancing is what makes the hedge exact.

## Solutions

**WC1: A (0.6)** = √(1 − 0.8²). That keeps Var(ε₂) = 0.64 + 0.36 = 1. B is 1 − 0.8 (not a square root). C would make the variance 1.28. D is 1 − 0.8², the variance, not the coefficient.

**WC2.** (a) ∂f/∂S = **3S²**, ∂²f/∂S² = **6S**, ∂f/∂t = **0**. (b) ΔΠ = (0 − ½ · 6S · σ²S²)Δt = **−3σ²S³Δt**. (c) −3 × 0.04 × 10⁶/252 = **−476.2**. (d) **No**: the μ terms from −Δf and from (∂f/∂S)ΔS cancel, exactly as the Δz terms do. The hedge needs only σ, not investors' expected return.

**WC3.** Seed 42: (a) σ̂ ≈ **23.4%**, standard error ≈ **1.0%**: the estimate sits about 1.5 standard errors below the true 25%. (b) Interval with σ̂: **74.2 to 142.1**; with the true σ: **72.5 to 144.9**. A 1.6-point volatility error narrows the interval by about 4.5 points. That's why estimation error matters when pricing options, which are very sensitive to σ (vega, coming in Module D).
